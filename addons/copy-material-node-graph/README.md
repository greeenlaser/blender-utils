# Copy material node graph

This is a full blender addon and can be added to Blender 4.5.x (and probably newer and older versions, but untested).

This utility adds a right-click context while in Shader Editor with two options. If you right-click on the empty background you can select `Copy Material Node Graph` to copy all active nodes and their connections to your clipboard. If you right click on a node and select `Copy Node` it only copies the contents of that node to the clipboard.
